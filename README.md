# Algorithmic Analysis & SmartLib System

A comprehensive Java-based backend project designed to benchmark advanced graph routing algorithms (Part 1) and demonstrate the computational complexity classes (P vs. NP) through a functional library management engine named SmartLib (Part 2).

---

## System Architecture
The project emphasizes raw computational evaluation and the application of Big-O theoretical limits to real-world software logic.

* **Language:** Java
* **Core Data Structures:** Directed Weighted Graphs, Hash Maps, Objects
* **Algorithms Implemented:** Bellman-Ford, Floyd-Warshall
* **Theoretical Scope:** Time and Space Complexity (Part 1), Polynomial-Time (P) vs. Non-Deterministic Polynomial-Time (NP) Analysis (Part 2)

---

## Core Modules

### Part 1: Shortest-Path Graph Routing
* **Algorithmic Execution:** Computes the shortest paths across dynamically scaled directed weighted graphs using both the Bellman-Ford and Floyd-Warshall algorithms.
* **Empirical Benchmarking:** Features a high-precision profiling engine that tracks algorithmic execution time down to the nanosecond (ns), comparing traversal efficiency across varying vertex densities (from 3 to 8+ nodes).

### Part 2: SmartLib Transaction Engine (P-Class Implementation)
* **Inventory & User Tracking:** A highly optimized transactional system managing `BookInventory` state and `Student` borrowing histories.
* **Polynomial-Time (P) Validations:** Demonstrates practical $O(1)$ and $O(N)$ efficiency through constant-time stock validation, automated quantity decrementing, and instant transaction recording.
* **NP-Complexity Evaluation:** Serves as a foundational model to conceptually explore how Non-Deterministic Polynomial-Time (NP) constraints affect system scalability.
